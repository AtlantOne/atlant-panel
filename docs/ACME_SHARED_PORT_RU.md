# HTTP-01 при занятом порте 80

В панели: Сертификаты → Автоматические сертификаты → Обработчик проверки
HTTP-01. Укажите `127.0.0.1:18081`, сохраните и перезапустите агент.
CLI: `atlant certlisten 127.0.0.1:18081`.

Существующий владелец внешнего порта 80 должен передавать путь проверки агенту.
Для nginx добавьте в соответствующий server-блок порта 80:

```nginx
location ^~ /.well-known/acme-challenge/ {
    proxy_pass http://127.0.0.1:18081;
    proxy_set_header Host $host;
    proxy_connect_timeout 2s;
    proxy_read_timeout 5s;
}
```

Проверьте `nginx -t`, затем примените конфигурацию nginx. Внешний порт проверки
остаётся 80; произвольный внешний порт центр сертификации не использует.
Остальные пути не передаются агенту. Нельзя использовать такой location,
если другая независимая ACME-служба обслуживает собственные проверки на этом же
виртуальном хосте: сначала нужно согласовать единого обработчика.

Дополнительные порты агент принимает только на literal loopback IP.
Host сохраняется для проверки соответствия домена и одноразового токена.
Настройка в панели не изменяет конфигурацию другого веб-сервера автоматически.
